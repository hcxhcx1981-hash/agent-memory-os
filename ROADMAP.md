# Roadmap

- **0.9 RC:** portable installation, fictional executable demos, documented
  contracts, license review, offline CI and public-release security checks.
- **1.0 stable:** compatibility review and documented operational boundaries;
  stable contract and packaging after RC feedback.
- **Future investigation:** optional semantic adapters, concurrency controls,
  cross-file transaction safety and additional host adapters.

No dates are promised. Future items are not implemented capabilities. The RC
does not add V0.3 features, a vector database, LLM dependency or other host adapters.
